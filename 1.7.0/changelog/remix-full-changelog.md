## Известные проблемы

|           **Проблема:** | Каркасное отображение (wireframe) во вьюпорте недоступно |
| ----------------------: | :------------------------------------------------------- |
|           **Описание:** | Мы ожидаем, что функция каркасного отображения будет недоступна длительное время. Приносим извинения за неудобства и искренне благодарим за терпение. |
|     **Обходной путь:** | Нет |
|             **Статус:** | _Приостановлено_ |
|  **Срок исправления:** | _Будет определён позже_. Если эта функция для вас приоритетна и вы хотите, чтобы мы ускорили её исправление, свяжитесь с нами по ссылке ниже. Ваши отзывы очень помогают нам расставлять приоритеты и решать проблемы пользователей. |
| **Затронутая версия:** | _Текущий выпуск_ |

|           **Проблема:** | Известная проблема: нельзя создавать проекты на дисках с файловой системой exFAT или FAT32 |
| ----------------------: | :---------------------------------------------------------------------------------------- |
|           **Описание:** | При попытке создать проект на диске с файловой системой exFAT может возникнуть проблема. Сейчас создание проектов на дисках с exFAT или FAT32 не поддерживается, и при создании проекта возникает ошибка. |
|     **Обходной путь:** | Создавайте проекты на дисках с файловой системой NTFS. |
|             **Статус:** | _Исправляться не будет_ |
|  **Срок исправления:** | _Будет определён позже_. Если эта функция для вас приоритетна и вы хотите, чтобы мы ускорили её исправление, свяжитесь с нами по ссылке ниже. Ваши отзывы очень помогают нам расставлять приоритеты и решать проблемы пользователей. |
| **Затронутая версия:** | _Текущий выпуск_ |
