# Журнал изменений RTX Remix Toolkit

Все значимые изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
а проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- Создана сборка 1.6.1-0
- Добавлены примечания к выпуску RTX Remix 1.6
- REMIX-6265: недопустимые выборки ComfyUI исключаются, а запросы с истёкшим тайм-аутом отменяются до запуска следующего задания ComfyUI. Добавлены сохраняемый тайм-аут 60 минут (0 — без ограничения), метки Timed Out цветом ошибки, Retry и возобновление очереди, пока продолжается активная работа. Добавлено действие Stop для графа задания, останавливающее выполняющееся задание и его запрос ComfyUI, с меткой Stopped и Retry. Действие AI Tools в Stage Manager отключено, если у рабочего процесса нет входа Selected Texture или Selected Mesh. Рабочий процесс ComfyUI только с входами Constant создаёт одно задание, текстурные входы должны соответствовать области действия входа-меша, а All Textures распространяет рабочие процессы для мешей без входа-меша на всю сцену. Рабочие процессы для текстур со входом-мешем применяют текстуры к материалам под этим мешем. Задокументированы типы рабочих процессов AI Tools, способы получения входных значений, тайм-аут задания и очередь заданий.
- REMIX-6266: добавлен фреймворк модификаторов ассетов (Asset Modifiers) для локальных преобразований моделей с сохраняемыми входами, действиями в Stage Manager, интеграцией с очередью заданий и обратимой заменой.
- REMIX-6266: в очередь заданий добавлен столбец Target, показывающий примы или файл модели каждого задания; добавлены руководства пользователя по очереди заданий и модификаторам ассетов, обновлено руководство по AI Tools и его скриншоты.

### Изменено

- Установлена версия разработки 1.7.0-dev
- Внутренний CI исключён из будущих коммитов зеркала на GitHub с сохранением ранее экспортированной истории и рабочих процессов GitHub.
- В записи о PR сообщества в примечаниях к выпуску RTX Remix 1.6 добавлены имена участников
- Packman обновлён до 8.7.0 с загрузчиком на Python 3.12, включая исправление ошибочного сообщения об успехе при неудачном переименовании `copyPath`.
- Размер каждой собранной версии документации уменьшен примерно с 1,5 ГБ до 182 МБ: 8 самых больших видео перекодированы из 4K в 1080p H.264, 65 больших изображений PNG преобразованы в JPEG
- Добавлены правила Remix Review на основе отзывов рецензентов: проверки упрощения изменения в целом и общих потребителей, правила по API, конфигурации, типизации, структуре модулей, области `extension.py`, форме ядра, повторному использованию механизмов Flux, отмене, изоляции виджетов, владению слоями, области макета окон, содержимому `.kit` приложения, фиксации зависимостей, тестовым настройкам, корневому экспорту, модульным тестам с обилием моков, достоверности тестов, комментариям к шагам E2E и опубликованной документации, а также учёт поглощения E2E в проверках избыточности тестов.
- Обновлены целевые зависимости Remix: hdremix и omni_core_materials до `ext-0b1da77-main`

- REMIX-3047: добавлен плавающий редактор цвета RGB/HSV/hex с предпросмотром в реальном времени и отменой для каждого жеста; незавершённые предпросмотры отменяются при удалении строки, обеспечена надёжная очистка полей цвета.

### Исправлено

- REMIX-6266: у сводной строки очереди заданий теперь собственный фон, чтобы она не сливалась со строками заданий.
- `tools/ci/scripts/notify_remix_target_dep_bot.sh` теперь использует совместимое с bash 3.2 удаление дубликатов каналов, чтобы его тесты проходили со стандартным `/bin/bash` macOS (ассоциативные массивы требуют bash 4.0+).
- Сборка документации ограничена версией `pydantic` из `deps/pip_flux.toml`, поскольку `pydantic` 2.14 сломал `autodoc` для параметризованных обобщённых моделей
- Исправлено периодическое зависание тестов: первый вызов USD в тесте мог взаимно блокироваться с предзагрузкой MDL, из-за чего `lss-e2e-tests-windows-a2s` теряли по 5 минут на задание и иногда завершались по тайм-ауту.
- Исправлена гонка в тестах удаления виджета очереди заданий: на медленных раннерах CI запрос на удаление открывался после падения теста, и открытое модальное окно блокировало щелчки во всех последующих тестах.
- Токен заметки к merge request больше не передаётся в командной строке curl в задании комментария об отсутствующих тестах, поэтому мониторинг процессов на раннерах CI его не записывает.
- Исправлена публикация документации с Packman 8: обновлён API поиска пакетов в инструменте документации.
- REMIX-6095: исправлены векторные атрибуты на панелях свойств, включая параметры MDL `float2`, которые вызывали `TypeError` и показывали неверные значения по умолчанию; исправлен сброс вектора, восстанавливавший значение по умолчанию не того канала. HdRemix и определения материалов обновлены до `ext-e62bf4b-main` для трансформаций текстур.
- Исправлена утечка в манипуляторе источников света: при каждом пересоздании манипулятора его модели источников оставались подписаны на все события сцены, из-за чего e2e-тесты панели свойств стали на 34% медленнее и приблизились к тайм-ауту расширения в CI. Исправлен нестабильный тест редактирования ComfyUI Timeout, использовавший двойной щелчок, который ломался на медленных кадрах.
- Исправлены отказы `github-mirror-sync` при изменении файлов LFS: теперь отправляются объекты LFS коммитов, отсутствующих в промежуточном зеркале, и проверяется наличие `git-lfs` на раннере
- Исправлены входы рабочих процессов ComfyUI, которые набор узлов помечает как `prompt`, `auto`, путь к приму, идентификатор слоя или неизвестный Toolkit тип: они отсутствовали в списке входов AI Tools, а теперь используют способы получения значений своего примитивного типа.
- Исправлено: `publish-etm-list` использовал дублирующийся блок правил, переопределявший задуманное поведение `when: always` для отправок в `main`.
- Исправлены ошибки запуска автономного IngestCraft: инициализация скрытого вьюпорта откладывается и возобновляется при показе, видимость предпросмотра импорта передаётся дальше.

### Удалено

- Удалены неиспользуемые инструменты: `tools/ci/vault/download_vault.ps1`, `tools/repoman/sign_archive.py`, `tools/repoman/launcher-pipeline-template/`, инструмент репозитория `auto_update_deps` с вспомогательным `print_published_extensions.py`, а также скрипты ручного тестирования в `tools/ci/scripts/`, `tools/crash_debug/` и `tools/migrations/tests/`. Их не вызывали ни задания CI, ни шаги сборки, ни скрипты, ни документация.
