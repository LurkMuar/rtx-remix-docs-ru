# Настройка RTX Remix Runtime для вашей игры

```{warning}
**Прежде чем настраивать игру, убедитесь, что RTX Remix Runtime установлен.**

Инструкции по установке RTX Remix Runtime приведены в разделе
[Установка RTX Remix Runtime](../installation/install-runtime.md).
```

Если вы впервые используете RTX Remix с какой-либо игрой, может понадобиться начальная настройка, чтобы меню и
изображение игры отображались правильно. Для этого используется меню разработчика RTX Remix.

```{note}
Настройка может отличаться в зависимости от игры, которую вы хотите превратить в ремастер.

Присоединяйтесь к [сообществу RTX Remix Showcase в Discord](https://discord.gg/c7J6gUhXMk): в канале
[remix-projects](https://discord.com/channels/1028444667789967381/1055020377430048848) можно получить помощь по игре,
которую вы хотите переделать!
```

## Что такое CONF-файлы

Давайте немного разберёмся с настройками меню **Alt+X**, а именно с вкладкой «Game Setup» (настройка игры). Во-первых,
здесь в виде сетки показан список материалов исходной игры. RTX Remix заполняет этот список на основе того, что
игра отрисовывает в данный момент. Список может меняться в зависимости от того, что отображается в игре (это
нормально). Он нужен, чтобы пользователям RTX Remix было удобно распределять материалы исходной игры по категориям
(см. раздел [Категории рендеринга](#категории-рендеринга)). Это помогает Remix понять, как обрабатывать
объекты исходной игры в современном рендерере.

Например, материалы, относящиеся в исходной игре к интерфейсу (UI), не нужно трассировать лучами. Если сообщить о них
Remix, он сможет отрисовать интерфейс средствами исходной игры, а обычно именно это и требуется.

Изменения, сделанные на вкладке Game Setup, сохраняются в файл конфигурации `RTX.conf`. Благодаря этому при следующем
запуске игры все ваши изменения сохранятся.

### CONF-файлы с ModDB

На [ModDB](https://www.moddb.com/rtx/) выложены файлы `RTX.conf` для многих игр, помогающие им наилучшим образом
работать с RTX Remix. Достаточно скачать файл `RTX.conf` и положить его вместе с RTX Remix Runtime рядом с исполняемым
файлом игры. Сообщество помогает поддерживать эти файлы `RTX.conf` на ModDB в актуальном состоянии, чтобы моддеры могли
легко подготовить игру к работе с RTX Remix.

## Категории рендеринга

Категории рендеринга (Render Categories) задают особые правила отрисовки определённых элементов. Вот некоторые важные
категории:

* UI (говорит Remix использовать для интерфейса рендеринг исходной игры);
* Sky (позволяет Remix создать реалистичную карту окружения);
* Particles (позволяет Remix правильно ориентировать эффекты частиц с учётом освещения и создавать эффект «мягких
  частиц»);
* Decals (говорит Remix обрабатывать эти материалы при трассировке пути как реалистичные декали);
* и т. д.

Эти категории в первую очередь помогают правильно рендерить в RTX Runtime, поэтому некоторые из них могут
отображаться в Remix Toolkit не совсем точно. Категорий гораздо больше. Если вы не уверены, что означает та или иная
категория, смотрите всплывающие подсказки в рантайме или документацию по конкретной настройке.

Изменения, сделанные на вкладке Game Setup, сохраняются в файл конфигурации `RTX.conf`. Благодаря этому при следующем
запуске игры все ваши изменения сохранятся. Полный список настроек (включая категории рендеринга) с описаниями приведён
в [этом документе](https://github.com/NVIDIAGameWorks/dxvk-remix/blob/main/RtxOptions.md).

```{note}
Категории рендеринга для мешей и материалов можно задавать и в RTX Remix Toolkit. Подробнее см. раздел
[Категории рендеринга](../toolkitinterface/remix-toolkitinterface-categories.md) документации по интерфейсу Toolkit.
```

## Настройка текстур интерфейса

Теперь, когда вы разобрались с CONF-файлами, начнём настраивать игру. Первым делом нужно настроить интерфейс (UI).

1. Нажмите `Alt+X`, чтобы открыть меню User Graphics Settings, затем выберите Developer Settings Menu (меню
   разработчика).
   ```{tip}
   В меню `Developer Settings` можно включить опцию `Always Developer Menu`, чтобы вместо `Graphics Settings Menu`
   всегда открывалось меню разработчика. Это удобно при настройке игры, когда к меню приходится обращаться часто.
   ```
2. В Developer Settings перейдите на вкладку `Game Setup`, затем в раздел `Step 1 – UI Textures`.
3. Щёлкните по всем текстурам, относящимся к интерфейсу игры (UI). Так вы сообщите RTX Remix, что их нужно
   обрабатывать как элементы интерфейса, а не как объекты игрового мира.
4. После разметки текстур интерфейса главное меню и игровой мир должны отображаться правильно.
5. Нажмите `Save Settings`, чтобы сохранить настройки текстур интерфейса в файл `rtx.conf`. Этот файл создаётся рядом с
   исполняемым файлом игры, поэтому повторять настройку не придётся.
6. Если позже найдутся ещё текстуры интерфейса, вы всегда можете вернуться в меню разметки UI.

## Захват сцены

RTX Remix умеет создавать точные копии игровых сцен в виде USD-файлов. Этот процесс называется «захватом» (capture).
Такие «захваты» можно открывать и редактировать в NVIDIA Omniverse и других популярных DCC-программах с поддержкой USD.
Поскольку сцена сохраняется в USD-файл, все ассеты оказываются в едином общем формате. Захватываются материалы,
текстуры, меши и данные скелета, а также экземпляры объектов и освещение конкретной сцены. Меши и материалы
конвертируются в формат USD, текстуры — в DDS. Эти копии сохраняются рядом с захватами в папках с соответствующими
названиями.

1. Перейдите на вкладку `Enhancements` в меню разработчика RTX Remix.
2. Убедитесь, что опция `Enable Enhanced Assets` (в подменю `Enhancements`) выключена.
3. Нажмите кнопку `Capture Scene`, чтобы начать захват.
   ```{tip}
   В поле `Name` можно задать имя захвата, чтобы потом его было легко найти.

   Если выбрать для захваченного файла расширение `USDA` вместо `USD`, сцена будет сохранена в виде читаемых текстовых
   файлов, что может пригодиться при отладке.
   ```
4. Так вы создадите свой первый захват игры. На его основе можно улучшать ассеты, материалы и освещение. Файлы захватов
   сохраняются в папку `rtx-remix/captures` рядом с исполняемым файлом игры. В папке `rtx_remix` также хранятся моды
   RTX Remix (в подпапке `mods`).

```{note}
На [ModDB](https://www.moddb.com/rtx) также есть готовые захваты, которые помогут начать работу над ремастером.
```

## Дальнейшие шаги

Всё настроено, и пора начинать ремастер игры с помощью RTX Remix Toolkit. Основная часть работы над модом — это замена
ассетов и текстур. Используя более детализированные модели и PBR-текстуры (Physically-Based Rendering, физически
корректный рендеринг), можно значительно повысить качество графики игры, намного превзойдя то, чего можно добиться
одними правками внутри движка.

Перейдите в раздел
[Настройка проекта в RTX Remix Toolkit](./learning-toolkitsetup.md#настройка-проекта-в-rtx-remix-toolkit),
чтобы узнать, как создать свой первый проект в RTX Remix Toolkit.
