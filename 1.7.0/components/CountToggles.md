# Count Toggles

Считает, сколько раз вход переключается из выключенного состояния во включённое.<br/><br/>Отслеживает, сколько раз логический вход переходит из false в true; полезно для подсчёта нажатий кнопки или смен состояния.

## Сведения о компоненте

- **Имя:** `CountToggles`
- **Имя в интерфейсе:** Count Toggles
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Bool | Input | false | Нет | 
| resetValue | Reset Value | Float | Input | 0\.0 | Нет | 

### Value

Входное логическое значение. Каждый раз, когда оно переходит из false в true, счётчик увеличивается.


### Reset Value

Когда счётчик достигает этого значения, он сбрасывается в 0. Если оставить 0, ничего не делает.


## Свойства состояния

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| prevFrameValue |  | Bool | State | true | Нет | 

###

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |

Текущее значение счётчика.

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
