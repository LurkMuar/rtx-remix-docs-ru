# Rtx Option Read Color4

Считывает текущее значение параметра RTX типа Color4 \(RGBA\).<br/><br/>Выдаёт текущее значение заданного параметра RTX как Color4. Внутри Color4 хранится как Vector4. Имя параметра должно быть полным, с категорией.

## Сведения о компоненте

- **Имя:** `RtxOptionReadColor4`
- **Имя в интерфейсе:** Rtx Option Read Color4
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| optionName | Option Name | String | Input | "" | Нет | 

### Option Name

Полное имя считываемого параметра RTX \(например, 'rtx\.someOption'\).


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float4 | Output | \[0\.0, 0\.0, 0\.0, 1\.0\] | Нет | 

### Value

Текущее значение параметра RTX как Color4 \(RGBA\). Если параметр не найден или не имеет тип Vector4, возвращается чёрный цвет с полной непрозрачностью \(0,0,0,1\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
