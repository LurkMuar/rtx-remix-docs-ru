# Invert

Выдаёт 1 минус входное значение.<br/><br/>Вычисляет 1 - вход. Полезно для инвертирования нормализованных значений \(например, превращения 0,2 в 0,8\).

## Сведения о компоненте

- **Имя:** `Invert`
- **Имя в интерфейсе:** Invert
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | NumberOrVector | Input | 0 | Нет | 

### Input

Инвертируемое значение.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| output | Output | NumberOrVector | Output | 0 | Нет | 

### Output

1 \- вход


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | input | output |
|---|---|---|
| 1 | Float | Float |
| 2 | Float2 | Float2 |
| 3 | Float3 | Float3 |
| 4 | Float4 | Float4 |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
