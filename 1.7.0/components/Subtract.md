# Subtract

Вычитает одно число или вектор из другого.<br/><br/>Вектор - число: число вычитается из всех компонент вектора. Если векторы разного размера, вычитание вектора из вектора завершается ошибкой.

## Сведения о компоненте

- **Имя:** `Subtract`
- **Имя в интерфейсе:** Subtract
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| a | A | NumberOrVector | Input | 0 | Нет | 
| b | B | NumberOrVector | Input | 0 | Нет | 

### A

Уменьшаемое \(значение, из которого вычитают\).


### B

Вычитаемое значение.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| difference | Difference | NumberOrVector | Output | 0 | Нет | 

### Difference

A \- B


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | a | b | difference |
|---|---|---|---|
| 1 | Float | Float | Float |
| 2 | Float2 | Float2 | Float2 |
| 3 | Float3 | Float3 | Float3 |
| 4 | Float4 | Float4 | Float4 |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
