# Between

Проверяет, попадает ли значение в диапазон \(включительно\).<br/><br/>Возвращает true, если значение >= Min Value И <= Max Value. Объединяет «больше или равно», «меньше или равно» и логическое И в одном компоненте.

## Сведения о компоненте

- **Имя:** `Between`
- **Имя в интерфейсе:** Between
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float | Input | 0\.0 | Нет | 
| minValue | Min Value | Float | Input | 0\.0 | Нет | 
| maxValue | Max Value | Float | Input | 1\.0 | Нет | 

### Value

Проверяемое значение.


### Min Value

Минимальное значение диапазона \(включительно\).


### Max Value

Максимальное значение диапазона \(включительно\).


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| result | Result | Bool | Output | false | Нет | 

### Result

True, если значение больше или равно Min Value И меньше или равно Max Value.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
