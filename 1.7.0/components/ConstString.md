# Constant String

Предоставляет задаваемую постоянную текстовую строку.<br/><br/>Используйте, чтобы передавать другим компонентам фиксированные текстовые значения, метки или идентификаторы.

## Сведения о компоненте

- **Имя:** `ConstString`
- **Имя в интерфейсе:** Constant String
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | String | Input | "" | Нет | 

### Value

Постоянная текстовая строка.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
