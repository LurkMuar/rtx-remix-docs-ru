# \[Non Functional\] Sphere Light

Изменяет свойства сферического источника света, например его радиус.<br/><br/>Примечание: этот компонент сейчас не работает, и его не следует использовать.

## Сведения о компоненте

- **Имя:** `SphereLightOverride`
- **Имя в интерфейсе:** \[Non Functional\] Sphere Light
- **Версия:** 1
- **Категории:** TODO

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| enabled | Enabled | Bool | Input | true | Да | 
| radius | Radius | Float | Input | 0\.0 | Да | 
| target | Target | Prim | Input | None | Нет | 

### Enabled

Если true, переопределения применяются.


### Radius

Радиус сферического источника света.


### Target

Переопределяемый сферический источник света.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
