# Constant Color3

Предоставляет задаваемый постоянный цвет RGB \(красный, зелёный, синий\).<br/><br/>Используйте, чтобы передавать фиксированные цвета материалам, источникам света или другим компонентам. Каждый канал — от 0,0 до 1,0.

## Сведения о компоненте

- **Имя:** `ConstColor3`
- **Имя в интерфейсе:** Constant Color3
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float3 | Input | \[0\.0, 0\.0, 0\.0\] | Нет | 

### Value

Постоянный цвет RGB \(красный, зелёный, синий\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
