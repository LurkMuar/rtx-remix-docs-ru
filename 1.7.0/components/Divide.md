# Divide

Делит одно число или вектор на другое.<br/><br/>Вектор / число: все компоненты вектора делятся на число. Вектор / вектор: компоненты делятся попарно — \(a\.x / b\.x, a\.y / b\.y, \.\.\.\). Если векторы разного размера, деление вектора на вектор завершается ошибкой.<br/><br/>Примечание: деление на ноль даёт бесконечность или NaN.

## Сведения о компоненте

- **Имя:** `Divide`
- **Имя в интерфейсе:** Divide
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| a | A | NumberOrVector | Input | 0 | Нет | 
| b | B | NumberOrVector | Input | 0 | Нет | 

### A

Делимое \(значение, которое делится\).


### B

Делитель \(значение, на которое делится\).


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| quotient | Quotient | NumberOrVector | Output | 0 | Нет | 

### Quotient

A / B


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | a | b | quotient |
|---|---|---|---|
| 1 | Float | Float | Float |
| 2 | Float2 | Float | Float2 |
| 3 | Float2 | Float2 | Float2 |
| 4 | Float3 | Float | Float3 |
| 5 | Float3 | Float3 | Float3 |
| 6 | Float4 | Float | Float4 |
| 7 | Float4 | Float4 | Float4 |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
