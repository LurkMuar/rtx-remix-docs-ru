# Bool NOT

Меняет значение true/false на противоположное.

## Сведения о компоненте

- **Имя:** `BoolNot`
- **Имя в интерфейсе:** Bool NOT
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | Bool | Input | false | Нет | 

### Input

Входное логическое значение.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| result | Result | Bool | Output | true | Нет | 

### Result

Логическое НЕ для входа \(инвертированное логическое значение\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
