# Time

Предоставляет непрерывно растущее значение времени для анимаций и эффектов, зависящих от времени.<br/><br/>Выдаёт время в секундах с момента создания компонента. Время можно приостанавливать и менять его скорость.

## Сведения о компоненте

- **Имя:** `Time`
- **Имя в интерфейсе:** Time
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| enabled | Enabled | Bool | Input | true | Да | 
| resetWhenDisabled | Reset When Disabled | Bool | Input | true | Да | 
| speedMultiplier | Speed Multiplier | Float | Input | 1\.0 | Да | 

### Enabled

Если true, время продолжает накапливаться. Если false, время приостановлено.


### Reset When Disabled

Если true, а \`enabled\` равно false, накопленное время сбрасывается в 0.


### Speed Multiplier

Множитель скорости времени. 1,0 — обычная скорость, 2,0 — двойная, 0,5 — половинная.


**Ограничения значения:**

- **Минимальное значение:** 0\.0

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
