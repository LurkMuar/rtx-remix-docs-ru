# Mesh Proximity

Измеряет, насколько точка удалена от ограничивающего параллелепипеда меша. Позволяет определить, находится ли камера рядом с мешем или внутри комнаты.<br/><br/>Вычисляет знаковое расстояние от точки в мировом пространстве до ограничивающего параллелепипеда меша. Положительные значения означают, что точка снаружи параллелепипеда, отрицательные — что внутри.<br/><br/>Учтите, что результат вычисляется в пространстве объекта, поэтому если меш масштабирован, расстояние может не соответствовать мировым единицам.

## Сведения о компоненте

- **Имя:** `MeshProximity`
- **Имя в интерфейсе:** Mesh Proximity
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| target | Target | Prim | Input | None | Нет | 
| worldPosition | World Position | Float3 | Input | \[0\.0, 0\.0, 0\.0\] | Нет | 
| inactiveDistance | Inactive Distance | Float | Input | 1\.0 | Да | 
| fullActivationDistance | Full Activation Distance | Float | Input | 0\.0 | Да | 
| easingType | Easing Type | Enum | Input | Linear | Да | 

### Target

Прим меша, ограничивающий параллелепипед которого используется. Должен быть примом UsdGeomMesh \(собственно геометрией\).


### World Position

Положение в мировом пространстве, проверяемое относительно ограничивающего параллелепипеда меша. Часто это выход \`Position\` компонента \`Camera\`, если нужно проверить, насколько камера близко к мешу.


### Inactive Distance

Когда \`World Position\` находится на этом расстоянии от ограничивающего параллелепипеда меша, \`Activation Strength\` равна 0. Положительные числа означают, что \`World Position\` снаружи параллелепипеда, отрицательные — что внутри.


### Full Activation Distance

Когда \`World Position\` находится на этом расстоянии от ограничивающего параллелепипеда меша, \`Activation Strength\` равна 1. Положительные числа означают, что \`World Position\` снаружи параллелепипеда, отрицательные — что внутри.


### Easing Type

Тип сглаживания \(easing\), применяемый к выходу \`Activation Strength\`.  

Базовый тип: `Enum`


**Допустимые значения:**

- Linear (`Linear`): значение меняется с постоянной скоростью. *(по умолчанию)*
- Cubic (`Cubic`): значение меняется по кубической кривой.
- EaseIn (`EaseIn`): значение сначала меняется медленно, затем ускоряется.
- EaseOut (`EaseOut`): значение сначала меняется быстро, затем замедляется.
- EaseInOut (`EaseInOut`): значение сначала меняется медленно, ускоряется, а затем замедляется.
- Sine (`Sine`): плавное естественное движение по синусоиде.
- Exponential (`Exponential`): эффект резкого ускорения.
- Bounce (`Bounce`): упругое, «подпрыгивающее» движение.
- Elastic (`Elastic`): пружинящее движение.

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| signedDistance | Signed Distance | Float | Output | 0\.0 | Нет | 
| activationStrength | Activation Strength | Float | Output | 0\.0 | Нет | 

### Signed Distance

Расстояние в пространстве объекта до ближайшей точки поверхности ограничивающего параллелепипеда. Положительное снаружи параллелепипеда, отрицательное внутри. Если подходящий ограничивающий параллелепипед не найден, выдаётся очень большое число. Поскольку расстояние вычисляется в пространстве объекта, при масштабировании объекта оно может не соответствовать мировым единицам.


### Activation Strength

Нормализованное значение 0–1: 0, когда \`Signed Distance\` = \`Inactive Distance\`, и 1, когда оно равно \`Full Activation Distance\`. Часто передаётся прямо на вход \`Blend Strength\` компонента \`Rtx Option Layer Action\`, чтобы включать conf-слой, когда камера рядом с мешем.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
