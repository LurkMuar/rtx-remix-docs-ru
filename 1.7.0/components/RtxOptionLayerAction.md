# Rtx Option Layer Action

Включает слои конфигурации и управляет ими во время работы в зависимости от игровых условий.<br/><br/>Управляет слоем RtxOptionLayer по имени, позволяя динамически включать и выключать его, настраивать силу и порог. Это позволяет активировать слои конфигурации во время работы в зависимости от состояния игры или других условий.<br/><br/>Если слоя нет, он создаётся; управление им ведётся с подсчётом ссылок.<br/>Если два компонента задают одинаковые приоритет и путь к конфигурации, они управляют одним и тем же слоем \(для включённых компонентов используется МАКСИМУМ сил смешивания и МИНИМУМ порогов смешивания\).<br/>Если два компонента задают одинаковый приоритет, но разные пути к конфигурации, приоритет слоёв определяется по алфавиту \(a\.conf переопределяет значения из z\.conf\).

## Сведения о компоненте

- **Имя:** `RtxOptionLayerAction`
- **Имя в интерфейсе:** Rtx Option Layer Action
- **Версия:** 1
- **Категории:** Act

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| configPath | Config Path | AssetPath | Input | "" | Нет | 
| enabled | Enabled | Bool | Input | true | Да | 
| blendStrength | Blend Strength | Float | Input | 1\.0 | Да | 
| blendThreshold | Blend Threshold | Float | Input | 0\.1 | Да | 
| priority | Priority | Float | Input | 10000\.0 | Да | 

### Config Path

Файл конфигурации управляемого слоя RtxOptionLayer.


### Enabled

Если true, слой параметров включён и его настройки применяются. Если false, слой выключен. Если одним слоем управляют несколько компонентов, он включается, если этого требует ХОТЯ БЫ ОДИН из них.


### Blend Strength

Сила смешивания слоя параметров \(0,0 — нет эффекта, 1,0 — полный эффект\).<br/><br/>Слой с наименьшим приоритетом смешивается со значением по умолчанию через линейную интерполяцию \(LERP\), затем каждый слой с более высоким приоритетом смешивается через LERP с результатом предыдущего слоя.<br/><br/>Если одним слоем управляют несколько компонентов, используется МАКСИМАЛЬНАЯ сила смешивания.


**Ограничения значения:**

- **Минимальное значение:** 0\.0
- **Максимальное значение:** 1\.0

### Blend Threshold

Порог смешивания для параметров нечислового типа \(не float\) \(от 0,0 до 1,0\). Такие параметры применяются, только когда сила смешивания превышает этот порог. Если одним слоем управляют несколько компонентов, используется МИНИМАЛЬНЫЙ порог смешивания.


**Ограничения значения:**

- **Минимальное значение:** 0\.0
- **Максимальное значение:** 1\.0

### Priority

Приоритет слоя параметров. Числа округляются до ближайшего положительного целого. Слои с большими значениями смешиваются поверх слоёв с меньшими. Если два компонента задают одинаковый приоритет, но разные пути к конфигурации, приоритет слоёв определяется по алфавиту \(a\.conf переопределяет значения из z\.conf\).


**Ограничения значения:**

- **Минимальное значение:** 101\.0
- **Максимальное значение:** \-2147483648\.0

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
