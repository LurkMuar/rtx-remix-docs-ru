# Angle to Mesh

Измеряет угол между лучом и центром меша. Позволяет определить, смотрит ли камера на меш.<br/><br/>Вычисляет угол между лучом \(заданным положением и направлением\) и направлением на трансформированный центроид меша.

## Сведения о компоненте

- **Имя:** `AngleToMesh`
- **Имя в интерфейсе:** Angle to Mesh
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| worldPosition | World Position | Float3 | Input | \[0\.0, 0\.0, 0\.0\] | Нет | 
| direction | Direction | Float3 | Input | \[0\.0, 0\.0, 1\.0\] | Нет | 
| target | Target | Prim | Input | None | Нет | 

### World Position

Положение в мировом пространстве, используемое как начало луча.


### Direction

Вектор направления луча \(нормализовать не обязательно\).


### Target

Прим меша, центроид которого используется. Должен быть примом меша.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| angleDegrees | Angle \(Degrees\) | Float | Output | 0\.0 | Нет | 
| angleRadians | Angle \(Radians\) | Float | Output | 0\.0 | Нет | 
| directionToCentroid | Direction to Centroid | Float3 | Output | \[0\.0, 0\.0, 0\.0\] | Нет | 

### Angle \(Degrees\)

Угол в градусах между направлением луча и направлением на центроид меша.


### Angle \(Radians\)

Угол в радианах между направлением луча и направлением на центроид меша.


### Direction to Centroid

Нормализованный вектор направления от мировой позиции к центроиду меша.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
