# Remap

Плавно переносит значение из одного диапазона в другой с настраиваемыми кривыми сглаживания.<br/><br/>Переносит значение из входного диапазона в выходной с необязательным сглаживанием. Значения нормализуются \(переносятся из входного диапазона в 0–1\), сглаживаются \(линейная зависимость меняется на кривую\), а затем переносятся \(значение 0–1 — в выходной диапазон\).<br/><br/>Примечание: входные значения вне входного диапазона допустимы, а сглаживание может приводить к выходу результата за пределы выходного диапазона, даже если вход находится внутри входного диапазона.<br/><br/>Инвертированные диапазоны \(max < min\) поддерживаются.

## Сведения о компоненте

- **Имя:** `Remap`
- **Имя в интерфейсе:** Remap
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float | Input | 0\.0 | Нет | 
| inputMin | Input Min | Float | Input | 0\.0 | Нет | 
| inputMax | Input Max | Float | Input | 1\.0 | Нет | 
| clampInput | Clamp Input | Bool | Input | false | Да | 
| easingType | Easing Type | Enum | Input | Linear | Нет | 
| shouldReverse | Should Reverse | Bool | Input | false | Да | 
| outputMin | Output Min | NumberOrVector | Input | 0 | Нет | 
| outputMax | Output Max | NumberOrVector | Input | 0 | Нет | 

### Value

Интерполируемое входное значение.


### Input Min

Если \`Value\` равно \`Input Min\`, на выходе будет \`Output Min\`.


### Input Max

Если \`Value\` равно \`Input Max\`, на выходе будет \`Output Max\`.


### Clamp Input

Если true, \`value\` ограничивается входным диапазоном.


### Easing Type

Применяемый тип сглаживания.

Базовый тип: `Enum`


**Допустимые значения:**

- Linear (`Linear`): значение меняется с постоянной скоростью. *(по умолчанию)*
- Cubic (`Cubic`): значение меняется по кубической кривой.
- EaseIn (`EaseIn`): значение сначала меняется медленно, затем ускоряется.
- EaseOut (`EaseOut`): значение сначала меняется быстро, затем замедляется.
- EaseInOut (`EaseInOut`): значение сначала меняется медленно, ускоряется, а затем замедляется.
- Sine (`Sine`): плавное естественное движение по синусоиде.
- Exponential (`Exponential`): эффект резкого ускорения.
- Bounce (`Bounce`): упругое, «подпрыгивающее» движение.
- Elastic (`Elastic`): пружинящее движение.

### Should Reverse

Если true, сглаживание применяется в обратном направлении. Если \`Value\` поступает от компонента Loop в режиме \`pingpong\`, соедините этот вход с его выходом \`isReversing\`.


### Output Min

Во что переводится \`Value\`, равное \`Input Min\`.


### Output Max

Во что переводится \`Value\`, равное \`Input Max\`.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |

| output | Output | NumberOrVector | Output | 0 | Нет | 

### Output

Итоговое значение после нормализации входа, сглаживания и переноса в выходной диапазон.
