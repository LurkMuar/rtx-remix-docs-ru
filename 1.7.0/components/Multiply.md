# Multiply

Перемножает два значения.<br/><br/>Вектор \* число: все компоненты вектора умножаются на число. Вектор \* вектор: компоненты перемножаются попарно — \(a\.x \* b\.x, a\.y \* b\.y, \.\.\.\). Если векторы разного размера, умножение вектора на вектор завершается ошибкой.

## Сведения о компоненте

- **Имя:** `Multiply`
- **Имя в интерфейсе:** Multiply
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| a | A | NumberOrVector | Input | 0 | Нет | 
| b | B | NumberOrVector | Input | 0 | Нет | 

### A

Первый множитель.


### B

Второй множитель.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| product | Product | NumberOrVector | Output | 0 | Нет | 

### Product

A \* B
