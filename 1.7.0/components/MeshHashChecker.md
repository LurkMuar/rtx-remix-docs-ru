# Mesh Hash Checker

Определяет, отрисовывается ли сейчас в сцене определённый меш.<br/><br/>Проверяются все меши, которые игра передаёт в Remix в текущем кадре, — вероятно, в том числе находящиеся вне кадра или перекрытые.

## Сведения о компоненте

- **Имя:** `MeshHashChecker`
- **Имя в интерфейсе:** Mesh Hash Checker
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| meshHash | Mesh Hash | Hash | Input | 0x0 | Нет | 

### Mesh Hash

Хеш меша, использование которого проверяется в текущем кадре.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| isUsed | Is Used | Bool | Output | false | Нет | 
| usageCount | Usage Count | Float | Output | 0\.0 | Нет | 

### Is Used

True, если хеш меша использовался в текущем кадре.


### Usage Count

Сколько раз хеш меша использовался в текущем кадре.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
