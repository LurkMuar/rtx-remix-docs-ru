# Constant Asset Path

Предоставляет задаваемый постоянный путь к файлу или ассету.<br/><br/>Используйте, чтобы передавать фиксированные пути к текстурам, моделям, файлам конфигурации или другим ассетам.

## Сведения о компоненте

- **Имя:** `ConstAssetPath`
- **Имя в интерфейсе:** Constant Asset Path
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | AssetPath | Input | "" | Нет | 

### Value

Постоянный путь к файлу или ассету.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
