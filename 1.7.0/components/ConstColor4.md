# Constant Color4

Предоставляет задаваемый постоянный цвет RGBA \(красный, зелёный, синий, альфа\).<br/><br/>Используйте для фиксированных цветов с прозрачностью. Каждый канал — от 0,0 до 1,0.

## Сведения о компоненте

- **Имя:** `ConstColor4`
- **Имя в интерфейсе:** Constant Color4
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float4 | Input | \[0\.0, 0\.0, 0\.0, 0\.0\] | Нет | 

### Value

Постоянный цвет RGBA \(красный, зелёный, синий, альфа\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
