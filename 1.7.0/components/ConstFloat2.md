# Constant Float2

Предоставляет задаваемый постоянный двумерный вектор \(два числа: X и Y\).<br/><br/>Используйте для фиксированных 2D-координат, текстурных координат или любой пары значений.

## Сведения о компоненте

- **Имя:** `ConstFloat2`
- **Имя в интерфейсе:** Constant Float2
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float2 | Input | \[0\.0, 0\.0\] | Нет | 

### Value

Постоянный двумерный вектор \(X, Y\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
