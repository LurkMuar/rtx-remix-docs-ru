# Rtx Option Read Bool

Считывает текущее значение логического параметра RTX.<br/><br/>Выдаёт текущее значение заданного логического параметра RTX. Имя параметра должно быть полным, с категорией \(например, 'rtx\.enableRaytracing'\).

## Сведения о компоненте

- **Имя:** `RtxOptionReadBool`
- **Имя в интерфейсе:** Rtx Option Read Bool
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| optionName | Option Name | String | Input | "" | Нет | 

### Option Name

Полное имя считываемого параметра RTX \(например, 'rtx\.someOption'\).


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Bool | Output | false | Нет | 

### Value

Текущее значение параметра RTX как bool. Если параметр не найден или не имеет тип bool, возвращается false.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
