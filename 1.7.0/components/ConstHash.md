# Constant Hash

Предоставляет задаваемое постоянное значение хеша.<br/><br/>Используйте, чтобы передавать фиксированные хеш-идентификаторы мешей, текстур или других ресурсов. Значения хешей обычно отображаются в шестнадцатеричном формате \(например, 0x1A2B3C4D\).

## Сведения о компоненте

- **Имя:** `ConstHash`
- **Имя в интерфейсе:** Constant Hash
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Hash | Input | 0x0 | Нет | 

### Value

Постоянное значение хеша.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
