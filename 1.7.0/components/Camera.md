# Camera

Предоставляет сведения о положении, направлении и поле зрения камеры.<br/><br/>Выдаёт текущие свойства камеры, включая положение, векторы ориентации и параметры проекции.<br/><br/>Использует свободную камеру, если включены и 'rtx\.camera\.useFreeCameraForComponents', и сама свободная камера.

## Сведения о компоненте

- **Имя:** `Camera`
- **Имя в интерфейсе:** Camera
- **Версия:** 1
- **Категории:** Sense

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| position | Position | Float3 | Output | \[0\.0, 0\.0, 0\.0\] | Нет | 
| forward | Forward | Float3 | Output | \[0\.0, 0\.0, \-1\.0\] | Нет | 
| right | Right | Float3 | Output | \[1\.0, 0\.0, 0\.0\] | Нет | 
| up | Up | Float3 | Output | \[0\.0, 1\.0, 0\.0\] | Нет | 
| fovRadians | FOV \(radians\) | Float | Output | 1\.047198 | Нет | 
| fovDegrees | FOV \(degrees\) | Float | Output | 60\.0 | Нет | 
| aspectRatio | Aspect Ratio | Float | Output | 1\.0 | Нет | 
| nearPlane | Near Plane | Float | Output | 0\.1 | Нет | 
| farPlane | Far Plane | Float | Output | 1000\.0 | Нет | 

### Position

Текущее положение камеры в мировом пространстве.


### Forward

Нормализованный вектор направления камеры вперёд в мировом пространстве.


### Right

Нормализованный вектор направления камеры вправо в мировом пространстве.


### Up

Нормализованный вектор направления камеры вверх в мировом пространстве.


### FOV \(radians\)

Вертикальное поле зрения камеры \(по оси Y\) в радианах. Значение всегда положительное.


### FOV \(degrees\)

Вертикальное поле зрения камеры \(по оси Y\) в градусах. Значение всегда положительное.


### Aspect Ratio

Соотношение сторон камеры \(ширина/высота\).


### Near Plane

Расстояние до ближней плоскости отсечения камеры.


### Far Plane

Расстояние до дальней плоскости отсечения камеры.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
