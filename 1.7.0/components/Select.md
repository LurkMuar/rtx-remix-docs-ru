# Select

Выбирает одно из двух значений в зависимости от логического условия.<br/><br/>Если условие истинно, выдаёт Input A, если ложно — Input B. Работает как тернарный оператор или конструкция if-else.

## Сведения о компоненте

- **Имя:** `Select`
- **Имя в интерфейсе:** Select
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| condition | Condition | Bool | Input | false | Нет | 
| inputA | Input A | Any | Input | 0 | Нет | 
| inputB | Input B | Any | Input | 0 | Нет | 

### Condition

Если true, выдаётся A. Если false — B.


### Input A

Значение, выдаваемое при истинном условии.


### Input B

Значение, выдаваемое при ложном условии.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| output | Output | Any | Output | 0 | Нет | 

### Output

Значение, выбранное в зависимости от условия.


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | condition | inputA | inputB | output |
|---|---|---|---|---|
| 1 | Bool | Bool | Bool | Bool |
| 2 | Bool | Float | Float | Float |
| 3 | Bool | Float2 | Float2 | Float2 |
| 4 | Bool | Float3 | Float3 | Float3 |
| 5 | Bool | Float4 | Float4 | Float4 |
| 6 | Bool | Enum | Enum | Enum |
| 7 | Bool | String | String | String |
| 8 | Bool | Hash | Hash | Hash |
| 9 | Bool | Prim | Prim | Prim |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
