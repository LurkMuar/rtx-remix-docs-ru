# Bool OR

Возвращает true, если A или B \(или оба\) равны true.

## Сведения о компоненте

- **Имя:** `BoolOr`
- **Имя в интерфейсе:** Bool OR
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| a | A | Bool | Input | false | Нет | 
| b | B | Bool | Input | false | Нет | 

### A

Первый логический вход.


### B

Второй логический вход.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| result | Result | Bool | Output | false | Нет | 

### Result

Логическое ИЛИ для A и B \(true, если A или B равно true\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
