# Round

Округляет значение до ближайшего целого.<br/><br/>Округляет до ближайшего целого числа. Например: 1,4 становится 1,0, 1,5 — 2,0, 1,6 — 2,0.

## Сведения о компоненте

- **Имя:** `Round`
- **Имя в интерфейсе:** Round
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | Float | Input | 0\.0 | Нет | 

### Input

Округляемое значение.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| result | Result | Float | Output | 0\.0 | Нет | 

### Result

Входное значение, округлённое до ближайшего целого.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
