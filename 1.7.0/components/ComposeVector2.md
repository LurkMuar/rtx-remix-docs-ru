# Compose Vector2

Объединяет два отдельных числа в один Vector2.

## Сведения о компоненте

- **Имя:** `ComposeVector2`
- **Имя в интерфейсе:** Compose Vector2
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| x | X | Float | Input | 0\.0 | Нет | 
| y | Y | Float | Input | 0\.0 | Нет | 

### X

Компонента X вектора.


### Y

Компонента Y вектора.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| vector | Vector | Float2 | Output | \[0\.0, 0\.0\] | Нет | 

### Vector

Составленный вектор.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
