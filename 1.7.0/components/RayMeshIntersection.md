# Ray Mesh Intersection

Проверяет, пересекает ли луч меш.<br/><br/>Выполняет проверку пересечения луча с мешем. Сейчас поддерживается проверка пересечения с ограничивающим параллелепипедом. Возвращает true, если луч пересекает ограничивающий параллелепипед меша.

## Сведения о компоненте

- **Имя:** `RayMeshIntersection`
- **Имя в интерфейсе:** Ray Mesh Intersection
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| rayOrigin | Ray Origin | Float3 | Input | \[0\.0, 0\.0, 0\.0\] | Нет | 
| rayDirection | Ray Direction | Float3 | Input | \[0\.0, 0\.0, 1\.0\] | Нет | 
| target | Target | Prim | Input | None | Нет | 
| intersectionType | Intersection Type | Enum | Input | Bounding Box | Да | 

### Ray Origin

Начальная точка луча в мировом пространстве.


### Ray Direction

Направление луча в мировом пространстве. Должно быть нормализовано.


### Target

Прим меша, с которым проверяется пересечение. Должен быть примом меша.


### Intersection Type

Тип выполняемой проверки пересечения.

Базовый тип: `Enum`


**Допустимые значения:**

- Bounding Box (`Bounding Box`): проверка пересечения с ограничивающим параллелепипедом меша, выровненным по осям. *(по умолчанию)*

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| intersects | Intersects | Bool | Output | false | Нет | 

### Intersects

True, если луч пересекает меш \(в соответствии с выбранным типом пересечения\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
