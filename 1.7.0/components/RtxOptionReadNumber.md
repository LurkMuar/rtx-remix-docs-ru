# Rtx Option Read Number

Считывает текущее значение числового параметра RTX.<br/><br/>Выдаёт текущее значение заданного параметра RTX. Поддерживаются типы float и int. Имя параметра должно быть полным, с категорией \(например, 'rtx\.pathTracing\.enableReSTIRGI'\).

## Сведения о компоненте

- **Имя:** `RtxOptionReadNumber`
- **Имя в интерфейсе:** Rtx Option Read Number
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| optionName | Option Name | String | Input | "" | Нет | 

### Option Name

Полное имя считываемого параметра RTX \(например, 'rtx\.someOption'\).


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float | Output | 0\.0 | Нет | 

### Value

Текущее значение параметра RTX как float. Если параметр не найден или не является числовым, возвращается 0.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
