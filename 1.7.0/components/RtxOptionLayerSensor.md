# Rtx Option Layer Sensor

Считывает состояние слоя конфигурации.<br/><br/>Выдаёт, включён ли заданный слой RtxOptionLayer, а также его силу и порог смешивания. Позволяет создавать логику, реагирующую на состояние слоёв конфигурации.

## Сведения о компоненте

- **Имя:** `RtxOptionLayerSensor`
- **Имя в интерфейсе:** Rtx Option Layer Sensor
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| configPath | Config Path | AssetPath | Input | "" | Нет | 
| priority | Priority | Float | Input | 10000\.0 | Да | 

### Config Path

Файл конфигурации считываемого слоя RtxOptionLayer.


### Priority

Приоритет слоя параметров. Числа округляются до ближайшего положительного целого. Слои с большими значениями смешиваются поверх слоёв с меньшими. Если у нескольких слоёв одинаковый приоритет, они упорядочиваются по алфавиту по пути к конфигурации.


**Ограничения значения:**

- **Минимальное значение:** 101\.0
- **Максимальное значение:** \-2147483648\.0

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| isEnabled | Is Enabled | Bool | Output | false | Нет | 
| blendStrength | Blend Strength | Float | Output | 0\.0 | Нет | 
| blendThreshold | Blend Threshold | Float | Output | 0\.0 | Нет | 

### Is Enabled

True, если слой параметров сейчас включён.


### Blend Strength

Текущая сила смешивания слоя параметров \(0,0 — нет эффекта, 1,0 — полный эффект\).


### Blend Threshold

Текущий порог смешивания для параметров нечислового типа \(от 0,0 до 1,0\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
