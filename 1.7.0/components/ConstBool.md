# Constant Bool

Предоставляет задаваемое постоянное значение true или false.<br/><br/>Используйте, чтобы передавать другим компонентам фиксированные значения вкл./выкл., да/нет или включено/выключено.

## Сведения о компоненте

- **Имя:** `ConstBool`
- **Имя в интерфейсе:** Constant Bool
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Bool | Input | false | Нет | 

### Value

Постоянное значение true/false.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
