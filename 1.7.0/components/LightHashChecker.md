# Light Hash Checker

Определяет, активен ли сейчас в сцене определённый источник света.<br/><br/>Проверяет, присутствует ли хеш источника света в таблице источников света текущего кадра.

## Сведения о компоненте

- **Имя:** `LightHashChecker`
- **Имя в интерфейсе:** Light Hash Checker
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| lightHash | Light Hash | Hash | Input | 0x0 | Нет | 

### Light Hash

Хеш источника света, использование которого проверяется в текущем кадре.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| isUsed | Is Used | Bool | Output | false | Нет | 

### Is Used

True, если хеш источника света использовался в текущем кадре.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
