# Decompose Vector3

Разделяет Vector3 на три отдельных числа.

## Сведения о компоненте

- **Имя:** `DecomposeVector3`
- **Имя в интерфейсе:** Decompose Vector3
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| vector | Vector | Float3 | Input | \[0\.0, 0\.0, 0\.0\] | Нет | 

### Vector

Раскладываемый вектор.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| x | X | Float | Output | 0\.0 | Нет | 
| y | Y | Float | Output | 0\.0 | Нет | 
| z | Z | Float | Output | 0\.0 | Нет | 

### X

Компонента X вектора \(красный канал\).


### Y

Компонента Y вектора \(зелёный канал\).


### Z

Компонента Z вектора \(синий канал\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
