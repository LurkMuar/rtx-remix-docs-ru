# Fog Hash Checker

Определяет, активно ли сейчас в сцене определённое состояние тумана.<br/><br/>Проверяет, совпадает ли заданный хеш тумана с хешем тумана текущего кадра.

## Сведения о компоненте

- **Имя:** `FogHashChecker`
- **Имя в интерфейсе:** Fog Hash Checker
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| fogHash | Fog Hash | Hash | Input | 0x0 | Нет | 

### Fog Hash

Хеш тумана, сравниваемый с хешем тумана текущего кадра.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| isMatch | Is Match | Bool | Output | false | Нет | 

### Is Match

True, если заданный хеш тумана совпадает с хешем тумана текущего кадра.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
