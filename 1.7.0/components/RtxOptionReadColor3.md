# Rtx Option Read Color3

Считывает текущее значение параметра RTX типа Color3 \(RGB\).<br/><br/>Выдаёт текущее значение заданного параметра RTX как Color3. Внутри Color3 хранится как Vector3. Имя параметра должно быть полным, с категорией \(например, 'rtx\.fallbackLightRadiance'\).

## Сведения о компоненте

- **Имя:** `RtxOptionReadColor3`
- **Имя в интерфейсе:** Rtx Option Read Color3
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| optionName | Option Name | String | Input | "" | Нет | 

### Option Name

Полное имя считываемого параметра RTX \(например, 'rtx\.someOption'\).


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float3 | Output | \[0\.0, 0\.0, 0\.0\] | Нет | 

### Value

Текущее значение параметра RTX как Color3 \(RGB\). Если параметр не найден или не имеет тип Vector3, возвращается чёрный цвет \(0,0,0\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
