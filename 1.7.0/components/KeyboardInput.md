# Keyboard Input

Определяет нажатие, удержание или отпускание клавиш клавиатуры.<br/><br/>Проверяет состояние клавиши или сочетания клавиш в том же формате, что и в параметрах RTX.

## Сведения о компоненте

- **Имя:** `KeyboardInput`
- **Имя в интерфейсе:** Keyboard Input
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| keyString | Key String | String | Input | "A" | Нет | 

### Key String

Строка с сочетанием клавиш.<br/>Примеры: 'A', 'CTRL, A', 'SHIFT, SPACE'.<br/>Полный список названий клавиш — в \`src/util/util\_keybind\.h\`.


## Свойства состояния

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| wasPressedLastFrame |  | Bool | State | false | Нет | 

### 

Внутреннее состояние, отслеживающее, была ли клавиша нажата в предыдущем кадре.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| isPressed | Is Pressed | Bool | Output | false | Нет | 
| wasJustPressed | Was Just Pressed | Bool | Output | false | Нет | 
| wasClicked | Was Clicked | Bool | Output | false | Нет | 

### Is Pressed

True, если сочетание клавиш нажато в данный момент.


### Was Just Pressed

True, если сочетание клавиш было нажато именно в этом кадре.


### Was Clicked

True в течение одного кадра после отпускания сочетания клавиш \(цикл «нажатие — отпускание»\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
