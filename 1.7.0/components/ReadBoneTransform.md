# Read Bone Transform

Считывает трансформацию \(положение, поворот, масштаб\) кости меша со скиннингом.<br/><br/>Извлекает данные трансформации определённой кости из прима меша со скиннингом. Выдаёт положение, поворот \(в виде кватерниона\) и масштаб в мировом пространстве. Если цель не является мешем со скиннингом или индекс кости недопустим, возвращается единичная трансформация.

## Сведения о компоненте

- **Имя:** `ReadBoneTransform`
- **Имя в интерфейсе:** Read Bone Transform
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| target | Target | Prim | Input | None | Нет | 
| boneIndex | Bone Index | Float | Input | 0\.0 | Нет | 

### Target

Прим меша, из которого считывается трансформация кости. Должен быть мешем со скиннингом.


### Bone Index

Индекс считываемой кости. Округляется до ближайшего целого.


**Ограничения значения:**

- **Минимальное значение:** 0\.0

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| position | Position | Float3 | Output | \[0\.0, 0\.0, 0\.0\] | Нет | 
| rotation | Rotation | Float4 | Output | \[0\.0, 0\.0, 0\.0, 1\.0\] | Нет | 
| scale | Scale | Float3 | Output | \[1\.0, 1\.0, 1\.0\] | Нет | 

### Position

Положение кости в мировом пространстве.


### Rotation

Поворот кости в мировом пространстве в виде кватерниона \(x, y, z, w\).


### Scale

Масштаб кости в мировом пространстве.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
