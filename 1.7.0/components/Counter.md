# Counter

Каждый кадр, пока условие истинно, увеличивает счётчик на заданную величину.<br/><br/>Увеличивает счётчик на заданное значение в каждом кадре, в котором логический вход равен true. Начальное значение счётчика задаётся параметром \`Starting Value\`. Полезно, чтобы отслеживать, сколько кадров условие было активно.

## Сведения о компоненте

- **Имя:** `Counter`
- **Имя в интерфейсе:** Counter
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| increment | Increment | Bool | Input | false | Нет | 
| incrementValue | Increment Value | Float | Input | 1\.0 | Да | 
| defaultValue | Starting Value | Float | Input | 0\.0 | Нет | 

### Increment

Пока true, счётчик каждый кадр увеличивается на величину приращения.


### Increment Value

Значение, прибавляемое к счётчику каждый кадр, пока increment равен true.


### Starting Value

Начальное значение счётчика при создании компонента.
