# Vector Length

Вычисляет длину \(модуль\) вектора.<br/><br/>Вычисляет евклидову длину вектора по формуле: sqrt\(x² \+ y² \+ z² \+ \.\.\.\).

## Сведения о компоненте

- **Имя:** `VectorLength`
- **Имя в интерфейсе:** Vector Length
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | NumberOrVector | Input | 0 | Нет | 

### Input

Измеряемое значение. Для векторов возвращается длина.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| length | Length | Float | Output | 0\.0 | Нет | 

### Length

Длина \(модуль\) входного вектора.


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | input | length |
|---|---|---|
| 1 | Float2 | Float |
| 2 | Float3 | Float |
| 3 | Float4 | Float |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
