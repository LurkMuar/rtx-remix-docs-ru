# Ceil

Округляет значение вверх до ближайшего целого.<br/><br/>Возвращает наименьшее целое, большее или равное входному значению. Например: 1,1 становится 2,0, 1,9 — 2,0, -1,1 — -1,0.

## Сведения о компоненте

- **Имя:** `Ceil`
- **Имя в интерфейсе:** Ceil
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | Float | Input | 0\.0 | Нет | 

### Input

Значение, округляемое вверх.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| result | Result | Float | Output | 0\.0 | Нет | 

### Result

Входное значение, округлённое вверх до ближайшего целого.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
