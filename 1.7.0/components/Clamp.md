# Clamp

Ограничивает значение заданным диапазоном.<br/><br/>Если значение меньше Min Value, возвращается Min Value. Если больше Max Value — Max Value. Иначе значение возвращается без изменений. Для векторов применяется к каждой компоненте отдельно.

## Сведения о компоненте

- **Имя:** `Clamp`
- **Имя в интерфейсе:** Clamp
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | NumberOrVector | Input | 0 | Нет | 
| minValue | Min Value | Float | Input | 0\.0 | Нет | 
| maxValue | Max Value | Float | Input | 1\.0 | Нет | 

### Value

Ограничиваемое значение.


### Min Value

Минимальное допустимое значение.


### Max Value

Максимальное допустимое значение.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| result | Result | NumberOrVector | Output | 0 | Нет | 

### Result

Ограниченное значение в диапазоне \[Min Value, Max Value\].


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | maxValue | minValue | result | value |
|---|---|---|---|---|
| 1 | Float | Float | Float | Float |
| 2 | Float | Float | Float2 | Float2 |
| 3 | Float | Float | Float3 | Float3 |
| 4 | Float | Float | Float4 | Float4 |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
