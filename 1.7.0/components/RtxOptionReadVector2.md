# Rtx Option Read Vector2

Считывает текущее значение параметра RTX типа Vector2.<br/><br/>Выдаёт текущее значение заданного параметра RTX типа Vector2. Имя параметра должно быть полным, с категорией \(например, 'rtx\.someVector2Option'\).

## Сведения о компоненте

- **Имя:** `RtxOptionReadVector2`
- **Имя в интерфейсе:** Rtx Option Read Vector2
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| optionName | Option Name | String | Input | "" | Нет | 

### Option Name

Полное имя считываемого параметра RTX \(например, 'rtx\.someOption'\).


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float2 | Output | \[0\.0, 0\.0\] | Нет | 

### Value

Текущее значение параметра RTX как Vector2. Если параметр не найден или не имеет тип Vector2, возвращается \(0,0\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
