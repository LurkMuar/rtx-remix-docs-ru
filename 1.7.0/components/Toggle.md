# Toggle

Переключатель, чередующий состояния «вкл.» \(true\) и «выкл.» \(false\).<br/><br/>Представьте выключатель света: в каждом кадре, когда \`Trigger Toggle\` равен true, переключатель переходит в противоположное положение. Параметр \`Starting State\` задаёт, во включённом или выключенном положении он начинает работу.

## Сведения о компоненте

- **Имя:** `Toggle`
- **Имя в интерфейсе:** Toggle
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| triggerToggle | Trigger Toggle | Bool | Input | false | Нет | 
| defaultState | Starting State | Bool | Input | false | Нет | 

### Trigger Toggle

Когда значение true, переключатель меняет состояние на противоположное \(вкл. становится выкл. и наоборот\). Задавайте true каждый раз, когда нужно щёлкнуть переключателем.


### Starting State

Начальное состояние переключателя при создании компонента. Задайте true, чтобы начать во включённом состоянии, или false — в выключенном.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| isOn | Is On | Bool | Output | false | Нет | 

### Is On

Текущее состояние переключателя: true — «вкл.», false — «выкл.». Начинается со значения \`Starting State\` и меняется каждый раз, когда \`Trigger Toggle\` становится true.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
