# Loop

Возвращает число обратно в диапазон, когда оно выходит за его границы.<br/><br/>Применяет к значению зацикливание. Если значение внутри диапазона, оно не меняется.<br/>Если Min Range == Max Range и тип зацикливания не None, компонент выдаёт Min Range.<br/>Инвертированные диапазоны \(max < min\) поддерживаются, но результат не определён и может измениться без предупреждения.

## Сведения о компоненте

- **Имя:** `Loop`
- **Имя в интерфейсе:** Loop
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | NumberOrVector | Input | 0 | Нет | 
| minRange | Min Range | NumberOrVector | Input | 0 | Нет | 
| maxRange | Max Range | NumberOrVector | Input | 0 | Нет | 
| loopingType | Looping Type | Enum | Input | Loop | Нет | 

### Value

Входное значение, к которому применяется зацикливание.


### Min Range

Минимальное значение диапазона зацикливания.


### Max Range

Максимальное значение диапазона зацикливания.


### Looping Type

Как значение зацикливается в пределах диапазона.

Базовый тип: `Enum`


**Допустимые значения:**

- Loop (`Loop`): значение переходит от max к min. *(по умолчанию)*
- PingPong (`PingPong`): значение движется туда и обратно между min и max.
- NoLoop (`NoLoop`): значение не меняется.
- Clamp (`Clamp`): значение ограничивается диапазоном.

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| loopedValue | Looped Value | NumberOrVector | Output | 0 | Нет | 
| isReversing | Is Reversing | Bool | Output | false | Нет | 

### Looped Value

Значение с применённым зацикливанием.


### Is Reversing

True, если значение находится в обратной фазе зацикливания «пинг-понг». Если вы передаёте \`loopedValue\` в компонент \`Remap\`, соедините этот выход с его входом \`shouldReverse\`.


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | isReversing | loopedValue | loopingType | maxRange | minRange | value |
|---|---|---|---|---|---|---|
| 1 | Bool | Float | Enum | Float | Float | Float |
| 2 | Bool | Float2 | Enum | Float2 | Float2 | Float2 |
| 3 | Bool | Float3 | Enum | Float3 | Float3 | Float3 |
| 4 | Bool | Float4 | Enum | Float4 | Float4 | Float4 |

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
