# Previous Frame Value

Выдаёт значение из предыдущего кадра.<br/><br/>Сохраняет входное значение и выдаёт его в следующем кадре. Полезно для обнаружения изменений между кадрами или реализации эффектов задержки.

## Сведения о компоненте

- **Имя:** `PreviousFrameValue`
- **Имя в интерфейсе:** Previous Frame Value
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | Any | Input | 0 | Нет | 

### Input

Значение, сохраняемое для следующего кадра.


## Свойства состояния

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| previousValue |  | Any | State | 0 | Нет | 

### 

Значение из предыдущего кадра.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| output | Output | Any | Output | 0 | Нет | 

### Output

Значение из предыдущего кадра.


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | input | output | previousValue |
|---|---|---|---|
| 1 | Bool | Bool | Bool |
| 2 | Float | Float | Float |
| 3 | Float2 | Float2 | Float2 |
| 4 | Float3 | Float3 | Float3 |
| 5 | Float4 | Float4 | Float4 |
| 6 | Enum | Enum | Enum |
| 7 | String | String | String |
| 8 | Hash | Hash | Hash |
| 9 | Prim | Prim | Prim |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
