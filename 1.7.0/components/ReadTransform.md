# Read Transform

Считывает трансформацию \(положение, поворот, масштаб\) меша или источника света в мировом пространстве.<br/><br/>Извлекает данные трансформации из заданного прима меша или источника света. Выдаёт положение, поворот \(в виде кватерниона\) и масштаб в мировом пространстве.

## Сведения о компоненте

- **Имя:** `ReadTransform`
- **Имя в интерфейсе:** Read Transform
- **Версия:** 1
- **Категории:** Sense

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| target | Target | Prim | Input | None | Нет | 

### Target

Прим меша или источника света, из которого считывается трансформация.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| position | Position | Float3 | Output | \[0\.0, 0\.0, 0\.0\] | Нет | 
| rotation | Rotation | Float4 | Output | \[0\.0, 0\.0, 0\.0, 1\.0\] | Нет | 
| scale | Scale | Float3 | Output | \[1\.0, 1\.0, 1\.0\] | Нет | 

### Position

Положение цели в мировом пространстве.


### Rotation

Поворот цели в мировом пространстве в виде кватерниона \(x, y, z, w\).


### Scale

Масштаб цели в мировом пространстве.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
