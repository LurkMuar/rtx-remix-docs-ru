# Smooth

Применяет к значению экспоненциальное сглаживание во времени.<br/><br/>Использует фильтр скользящего среднего, чтобы сгладить резкие изменения входного значения. Коэффициент сглаживания определяет степень сглаживания: при 0 выход никогда не меняется. Чем больше значение, тем быстрее изменения. <br/>

## Сведения о компоненте

- **Имя:** `Smooth`
- **Имя в интерфейсе:** Smooth
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | NumberOrVector | Input | 0 | Нет | 
| smoothingFactor | Smoothing Factor | Float | Input | 0\.1 | Да | 

### Input

Сглаживаемое значение.


### Smoothing Factor

Коэффициент сглаживания \(0–1000\). При 0 выход никогда не меняется. Чем больше значение, тем быстрее изменения.<br/><br/>Время, за которое выход приближается к входу с точностью 1%, при разных коэффициентах:<br/>\- 1: 6,6 секунды<br/>\- 10: 0,66 секунды<br/>\- 100: 0,066 секунды<br/>\- 1000: 0,0066 секунды<br/><br/>Формула: output = lerp\(input, previousOutput, exp2\(\-smoothingFactor\*deltaTime\)\)


**Ограничения значения:**

- **Минимальное значение:** 0\.0
- **Максимальное значение:** 1000\.0
