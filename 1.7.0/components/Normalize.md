# Normalize

Нормализует вектор до длины 1.<br/><br/>Делит вектор на его длину, получая единичный вектор \(длины 1\) того же направления. Если длина входного вектора равна нулю, возвращается вектор по умолчанию, чтобы избежать деления на ноль.

## Сведения о компоненте

- **Имя:** `Normalize`
- **Имя в интерфейсе:** Normalize
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | NumberOrVector | Input | 0 | Нет | 

### Input

Нормализуемый вектор.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| output | Output | NumberOrVector | Output | 0 | Нет | 

### Output

Нормализованный вектор длины 1. Если длина входного вектора равна нулю, возвращается \(0,1\), \(0,0,1\) или \(0,0,0,1\).


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | input | output |
|---|---|---|
| 1 | Float2 | Float2 |
| 2 | Float3 | Float3 |
| 3 | Float4 | Float4 |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
