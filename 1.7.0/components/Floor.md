# Floor

Округляет значение вниз до ближайшего целого.<br/><br/>Возвращает наибольшее целое, меньшее или равное входному значению. Например: 1,1 становится 1,0, 1,9 — 1,0, -1,1 — -2,0.

## Сведения о компоненте

- **Имя:** `Floor`
- **Имя в интерфейсе:** Floor
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | Float | Input | 0\.0 | Нет | 

### Input

Значение, округляемое вниз.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| result | Result | Float | Output | 0\.0 | Нет | 

### Result

Входное значение, округлённое вниз до ближайшего целого.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
