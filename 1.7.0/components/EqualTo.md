# Equal To

Возвращает true, если A равно B, иначе false.<br/><br/>Для чисел с плавающей точкой выполняется точное сравнение на равенство. При сравнении вектора с вектором сравниваются все компоненты.

## Сведения о компоненте

- **Имя:** `EqualTo`
- **Имя в интерфейсе:** Equal To
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| a | A | NumberOrVector | Input | 0 | Нет | 
| b | B | NumberOrVector | Input | 0 | Нет | 
| tolerance | Tolerance | Float | Input | 0\.00001 | Нет | 

### A

Первое сравниваемое значение.


### B

Второе сравниваемое значение.


### Tolerance

Допуск на ошибки округления. Операции с числами с плавающей точкой неточны, поэтому при сравнении на равенство следует допускать небольшие расхождения. Если разница между A и B меньше Tolerance, результат будет true.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| result | Result | Bool | Output | false | Нет | 

### Result

True, если A == B, иначе false


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | a | b | result | tolerance |
|---|---|---|---|---|
| 1 | Float | Float | Bool | Float |
| 2 | Float2 | Float2 | Bool | Float |
| 3 | Float3 | Float3 | Bool | Float |
| 4 | Float4 | Float4 | Bool | Float |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
