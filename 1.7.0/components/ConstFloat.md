# Constant Number

Предоставляет задаваемое постоянное дробное число.<br/><br/>Используйте, чтобы передавать другим компонентам фиксированные значения вроде 0,5, 3,14 или 100,0.

## Сведения о компоненте

- **Имя:** `ConstFloat`
- **Имя в интерфейсе:** Constant Number
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float | Input | 0\.0 | Нет | 

### Value

Постоянное дробное число.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
