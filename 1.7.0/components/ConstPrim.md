# Constant Prim

Предоставляет задаваемую постоянную ссылку на объект сцены \(прим\).<br/><br/>Используйте, чтобы передавать фиксированные ссылки на меши, источники света, камеры или другие элементы сцены.

## Сведения о компоненте

- **Имя:** `ConstPrim`
- **Имя в интерфейсе:** Constant Prim
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Prim | Input | None | Нет | 

### Value

Постоянная ссылка на прим.


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
