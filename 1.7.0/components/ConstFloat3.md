# Constant Float3

Предоставляет задаваемый постоянный трёхмерный вектор \(три числа: X, Y, Z\).<br/><br/>Используйте для фиксированных 3D-положений, цветов RGB, направлений или любого набора из трёх значений.

## Сведения о компоненте

- **Имя:** `ConstFloat3`
- **Имя в интерфейсе:** Constant Float3
- **Версия:** 1
- **Категории:** Constants

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| value | Value | Float3 | Input | \[0\.0, 0\.0, 0\.0\] | Нет | 

### Value

Постоянный трёхмерный вектор \(X, Y, Z\).


## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
