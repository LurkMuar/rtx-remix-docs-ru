# Velocity

Определяет скорость изменения значения от кадра к кадру.<br/><br/>Вычисляет разность между текущим значением и значением в предыдущем кадре. Выдаёт изменение за кадр \(velocity = \(current \- previous\) / deltaTime\).

## Сведения о компоненте

- **Имя:** `Velocity`
- **Имя в интерфейсе:** Velocity
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| input | Input | NumberOrVector | Input | 0 | Нет | 

### Input

Значение, изменения которого отслеживаются.


## Свойства состояния

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| previousValue |  | NumberOrVector | State | 0 | Нет | 

### 

Значение из предыдущего кадра.


## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| velocity | Velocity | NumberOrVector | Output | 0 | Нет | 

### Velocity

Изменение значения по сравнению с предыдущим кадром: \(current \- previous\) / deltaTime.


## Допустимые сочетания типов

Этот компонент поддерживает гибкие типы. Допустимы следующие сочетания типов:

| # | input | previousValue | velocity |
|---|---|---|---|
| 1 | Float | Float | Float |
| 2 | Float2 | Float2 | Float2 |
| 3 | Float3 | Float3 | Float3 |
| 4 | Float4 | Float4 | Float4 |

## Примечания по использованию

Этот компонент входит в систему графов RTX Remix и предназначен для использования только в Remix Toolkit и рантайме.
