# Conditionally Store

Сохраняет значение, когда условие истинно, иначе сохраняет предыдущее значение.<br/><br/>Если вход store равен true, входное значение захватывается и сохраняется. Если false, продолжает выдаваться ранее сохранённое значение. Полезно для поведения «выборка и хранение» \(sample-and-hold\).

## Сведения о компоненте

- **Имя:** `ConditionallyStore`
- **Имя в интерфейсе:** Conditionally Store
- **Версия:** 1
- **Категории:** Transform

## Входные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| store | Store | Bool | Input | false | Нет | 
| input | Input | Any | Input | 0 | Нет | 

### Store

Если true, входное значение записывается в состояние. Если false, сохраняется предыдущее значение.


### Input

Значение, которое сохраняется, когда store равен true.


## Свойства состояния

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
|----------|--------------|------|---------|---------------|----------|
| storedValue |  | Any | State | 0 | Нет | 

###

## Выходные свойства

| Свойство | Отображаемое имя | Тип | Тип ввода-вывода | Значение по умолчанию | Необязательное |
