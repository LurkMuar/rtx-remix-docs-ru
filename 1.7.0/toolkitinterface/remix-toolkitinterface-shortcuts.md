# Сочетания клавиш

## Глобальные сочетания клавиш

|      Клавиши     | Описание                                |
|:----------------:|:----------------------------------------|
|     Ctrl + S     | Сохранить проект                        |
| Ctrl + Shift + S | Сохранить проект как                    |
|     Ctrl + Z     | Отменить                                |
|     Ctrl + Y     | Повторить                               |
|     Ctrl + Y     | Повторить                               |
|       ESC        | Снять выделение со всех выделенных объектов |
|     Ctrl + A     | Выделить все примы с данными, которые отображаются на активной вкладке Stage Manager с учётом пользовательских фильтров, даже если курсор мыши находится вне Stage Manager. Сюда входят предки и потомки в иерархии, в том числе в свёрнутых ветвях; корневой узел захвата `RootNode` и синтетические строки группировки не выделяются. В текстовом поле это сочетание выделяет текст. |

## Сочетания клавиш вьюпорта

| Клавиши  | Описание                                                                           |
|:--------:|:-----------------------------------------------------------------------------------|
|    F     | Показать выделенное (Frame Selection)                                              |
|    Q     | Инструмент выделения                                                               |
|    W     | Инструмент перемещения                                                             |
|    E     | Инструмент вращения                                                                |
|    R     | Инструмент масштабирования                                                         |
|    S     | Инструмент привязки (Snapping)                                                     |
| Ctrl + T | Инструмент телепортации: перемещает выделенный объект в точку под курсором.        |
